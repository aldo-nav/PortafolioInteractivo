
# Portafolio Interactivo - Nova Studio
Proyecto académico de una landing page responsiva para un negocio ficticio de diseño y desarrollo web.
## Tecnologías utilizadas
- HTML5 para la estructura de la página.
- Bootstrap 5.3.3 para Navbar, Grid, formulario y botones.
- CSS externo para estilos, transformaciones y animaciones.
- JavaScript externo para validación y controles interactivos.
## Transformaciones 2D
- rotate(3deg): hace girar la primera tarjeta.
- scale(1.06): aumenta el tamaño de la segunda tarjeta.
- translateY(-14px): desplaza hacia arriba la tercera tarjeta.
- transition: permite que los cambios sean suaves.
## Transformación 3D
- perspective:1100px para generar profundidad.
- transform-style:preserve-3d para conservar el efecto tridimensional.
- rotateX(12deg) y rotateY(180deg) para girar la tarjeta.
## Animaciones CSS
- @keyframes entradaTitulo: aparición del título desde abajo.
- @keyframes giroContinuo: cargador circular infinito.
- @keyframes latido: animación del indicador verde.
- Uso de animation-duration, animation-timing-function y animation-iteration-count.
## Cómo ejecutar
1. Abrir la carpeta PortafolioInteractivo en Visual Studio Code.
2. Abrir index.html utilizando Live Server.
3. Mantener conexión a Internet para cargar Bootstrap desde el CDN.
4. Probar la navegación, tarjetas, animaciones y formulario.
